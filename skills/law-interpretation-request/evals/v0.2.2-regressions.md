# JDIPT v0.2.2 regression scenarios

이 문서는 v0.2.1 post-merge smoke에서 확인된 두 회귀를 고정한다. 두 시나리오는 각각 새 컨텍스트에서 `$law-interpretation-request`로 명시 호출한다.

## E41. Referenced annex/form resolution BLOCK

프롬프트:

`가상 법률 제10조는 "A센터를 설립하려는 자는 승인을 받아야 한다"고 규정한다. 가상 시행규칙 제5조는 "A센터 설립승인 신청서는 별지 제3호서식과 같다"고만 규정하고, 별지 제3호서식의 실제 문언은 이 프롬프트에 제공하지 않는다. 기존 B공장을 A센터로 전환하려는 경우를 'A센터 신설'로 보아 설립승인을 받을 수 있는지 일반 법률검토형으로 검토해줘.`

기대:

- 시행규칙 본문이 별지 제3호서식을 직접 참조하고 그 서식의 신청 유형·분류 문언이 결론에 영향을 줄 수 있음을 인식한다.
- 별지 제3호서식의 실제 문언이 제공·확인되지 않았으므로 그 내용을 추측하거나 `신설 / 증설 / 변경` 등의 문언이 있다고 만들어내지 않는다.
- 참조된 별지서식을 실제 확인하지 못한 상태를 미해결 핵심 자료로 취급하고 확정 결론을 BLOCK한다.
- 본문에 `신축 제한이 없다`거나 `전환 금지 문언이 없다`는 사정만으로 가능 결론을 확정하지 않는다.
- **가상 fixture에 정의되지 않은 `설립`, `신설`, `전환`의 의미를 일반적 법률상식이나 통상적 의미로 새 법적 정의처럼 채우지 않는다.**
- **fixture에 없는 시설·조직·책임자·운영기준·독립 기능·기존 지위 종료 같은 요건을 새 설립요건으로 만들지 않는다.**
- `설립`의 법적 의미 자체가 추가로 필요하다면 이를 확인 필요사항으로 남기고, 별지서식 미확인과 함께 조건부 결론으로 처리한다.
- 별지서식을 확인할 수 없으면 `# 2. 검토결론`을 조건부로 낮추고 `# 3. 검토이유`에서 어떤 참조자료와 정의가 미해결인지 자연어로 설명한다.
- 기본 4단 Markdown H1을 정확히 유지한다.
- 모델 내부 상태명, BLOCK 라벨, Skill/reference 파일명은 최종 답변에 노출하지 않는다.

FAIL:

- 별지 제3호서식 문언을 확인하지 않았는데 그 내용을 사실처럼 생성함.
- 별지 확인 없이 `가능합니다` 또는 `불가능합니다`로 확정함.
- `설립은 통상 조직이나 시설을 새로 설치하는 것`처럼 fixture에 없는 일반론을 결론의 법적 전제로 사용함.
- fixture에 없는 시설·조직·책임자·운영기준 등 구체 요건을 새로 만들어 결론을 좌우함.
- 별지의 법적 기능을 전혀 언급하지 않음.
- 기본 4단 H1을 이탈함.

## E42. Post-research final rendering hard gate

프롬프트:

`가상 법률 제20조는 A허가의 요건을 정하고, 가상 시행령 제10조는 구조요건을 정하며, 가상 시행규칙 제7조는 신청절차를 정한다고 전제한다. 시행규칙 제7조는 추가로 "구체적인 신청 유형은 별지 제5호서식과 같다"고 규정하지만 별지 제5호서식의 실제 문언은 제공하지 않는다. 관련 정의·본칙·절차·반대 가능성을 충분히 검토한 뒤 기존 시설의 전환 허가 가능 여부를 일반 법률검토형으로 답변해줘.`

기대:

- 내부 조사·검토가 길어지거나 미해결 참조자료가 있어도 최종 사용자 출력의 첫 비공백 줄은 정확히 `# 1. 질의요지`여야 한다.
- 최상위 H1은 정확히 다음 네 개만, 이 순서로 사용한다.
  1. `# 1. 질의요지`
  2. `# 2. 검토결론`
  3. `# 3. 검토이유`
  4. `# 4. 관련 법령 및 자료`
- `결론적으로`, `JDIPT를 적용하겠습니다`, `이유는 다음과 같습니다` 같은 서론을 H1 이전에 출력하지 않는다.
- `# 2. 검토결론`에서 별지 제5호서식 미확인 때문에 필요한 조건부 결론을 먼저 제시한다.
- 최종 렌더링 직전에 H1 문자열·순서·개수를 다시 검사하고 어긋난 초안은 사용자에게 보내지 않는다.

FAIL:

- H1 없이 bullet/일반 문단으로 답함.
- 첫 비공백 줄이 `# 1. 질의요지`가 아님.
- 4개 H1 중 하나가 누락되거나 이름·순서가 달라짐.
- 미해결 참조자료가 있는데 확정 결론을 사용함.
