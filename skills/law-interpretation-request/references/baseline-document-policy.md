# 업로드 기준 문서 반영 규칙

사용자가 샘플, 기존 질의서, 기관 서식, 회신문, 내부 검토서 등을 업로드하면 다음을 먼저 추출한다.

- 문서 목적과 제출기관
- 목차와 번호 체계
- 제목 작성 방식
- 질의요지의 길이와 문장 구조
- 사실관계를 넣는 위치와 분량
- 법령 인용 형식
- 갑설·을설 또는 검토의견 배열
- 문단 표지(`○`, `-`, `가.`, `나.` 등)
- 각주·첨부자료 표기 방식
- 종결 표현과 문체

## 충돌 우선순위

`사용자의 최신 명시 지시 > 업로드 기준 문서 > 스킬 기본 형식`

예: 업로드된 법제처 샘플에 4~8번 항목이 있어도, 사용자가 법제처 작성 모드에서 1~3번만 쓰라고 지시했으므로 4~8은 출력하지 않는다.

## 복제 금지

기준 문서의 고유 사실관계, 기관명, 사건번호, 당사자, 조문을 새 사안에 그대로 복제하지 않는다. 형식·논리 전개·문체만 참고하고 새 사안에 맞게 다시 작성한다.
