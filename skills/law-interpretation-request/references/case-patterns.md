## 세 가지 핵심 Issue Mapping 패턴

### A. 법적 분류형 — 22-0351

대상의 법적 분류가 어느 본칙·예외를 적용할지를 결정하는 유형이다.

```text
대상 정의
→ 상위·하위 법적 분류
→ 본칙 확인
→ 예외 또는 특례 적용대상인지 확인
→ 사용자 사실에 대입
→ 결론
```

이 유형에서는 단순히 사용자가 부른 명칭을 그대로 사용하지 않고 법정 정의와 분류체계에서 실제 위치를 먼저 확정한다. 다만 최종 답변에서는 `정의`, `본칙`, `예외`, `사안 적용`을 각각 소제목으로 분절하지 말고 하나의 논증으로 연결한다.

### B. 중복규율형 — 17-0047

서로 다른 법령이 같은 행위·시설·산정기준을 각각 규율하는 것처럼 보이는 유형이다.

```text
규정 A의 규율대상·기능
+
규정 B의 규율대상·기능
→ 동일 사항의 중복 규율인지 확인
→ 일반/특별, 배타적 적용 또는 누적 적용 여부 판단
→ 결론
```

`특별법 우선`이라는 표지만으로 결론내리지 않고 두 규정이 실제로 **동일한 사항**을 규율하는지 먼저 확인한다.

### C. 규율공백형 — 20-0604

특별법이 관련 분야를 규율하고 있지만 질문의 구체 사항 자체는 규정하지 않은 유형이다.

```text
특별법 규율범위 확인
→ 질문의 구체 사항을 직접 규율하는 조항 존재 여부
→ 없음 = 규율 공백
→ 일반법의 보충 적용 가능성 검토
→ 결론
```

중복규율형과 규율공백형을 혼동하지 않는다. 특별법이 해당 분야를 전반적으로 규율한다는 이유만으로 그 법에 없는 세부 기준까지 일반법의 적용이 배제된다고 단정하지 않는다.

## 법제처 해석례의 출력·서술 패턴

법제처 공개 해석례는 대체로 다음 순서로 독자가 결론을 먼저 파악하게 한다.

```text
질의요지
→ 회답(결론)
→ 이유(연속된 법적 논증)
→ 관계 법령
```

`이유`에서는 정의·직접 규정·규정 관계·사안 적용·반대논거·입법연혁 등을 필요에 따라 사용하지만, 하나의 쟁점을 내부 분석 단계별 제목으로 과도하게 분할하지 않는다. 이유 말미에는 `따라서 ...`와 같이 회답과 동일한 결론을 다시 확인하는 구조가 반복된다.

이 문서의 패턴은 JDIPT 기본 법률검토형에서 다음 원칙으로 적용한다.

- 상세 이유보다 검토결론을 먼저 제시한다.
- 이유 안에서는 법적 정의와 규정, 질문의 사실관계를 자연스럽게 연결한다.
- 소제목은 서로 독립적인 복수 법적 쟁점이 있을 때만 사용한다.
- 결론을 먼저 **작성**하는 것이 아니라 내부 분석·논리검증으로 결론을 확정한 뒤 사용자 출력에서 먼저 **배치**한다.

## 자주 반복되는 법제처 문장 구조

### 해석 원칙 제시
- `법해석의 목표는 ... 법적 안정성을 저해하지 않는 범위에서 구체적 타당성을 찾는 데 두어야 하고 ... 문언의 통상적인 의미에 충실하게 해석하는 것을 원칙으로 하면서 ... 체계적·논리적 해석방법을 추가적으로 동원...`
- `법령의 문언 자체가 비교적 명확한 개념으로 구성되어 있다면 원칙적으로 더 이상 다른 해석방법은 활용할 필요가 없거나 제한될 수밖에...`
- `일정한 원칙에 대한 예외 규정을 해석할 때에는 합리적인 이유 없이 문언의 의미를 확대 해석할 수 없다...`

직접 인용은 필요한 최소 범위만 사용하고, 실제 제출문에서는 해당 사건에 맞게 자연스럽게 재서술한다.

## 갑설·을설 작성에 적용

1. 각 설의 첫 문단은 가장 직접적인 문언 근거를 둔다.
2. 다음 문단에서 정의규정·제외문구·본문/단서·위임관계를 검토한다.
3. 문언만으로 불분명할 때 체계·목적·연혁을 추가한다.
4. 판례·해석례는 사실관계와 조문 버전이 유사한 경우에만 보강한다.
5. 반대설의 가장 강한 논거를 생략하지 않는다.
6. 각 설 마지막은 `따라서 ...`로 회신 가능한 결론을 명시한다.
