# 법령해석 대상 적합성 내부 체크리스트

이 체크리스트는 **내부 판단용**이다. 법제처 제출용 최종 문안의 4~8번 항목으로 출력하지 않는다.

## A. 기본 적합성

- [ ] 해석 대상이 법률·대통령령·총리령·부령 등 법령의 규정인가?
- [ ] 해석 대상 법령과 조문이 특정되어 있는가?
- [ ] 질문의 전제사실과 해당 조문 사이에 실질적 연관성이 있는가?
- [ ] 단순 정책 선택이 아니라 법규범의 의미·범위를 묻는가?
- [ ] 문언상 결론이 완전히 명백하여 별도 해석이 불필요한 사안은 아닌가?

## B. 제외 가능성이 큰 유형

다음이면 법제처 법령해석 대상으로 부적합할 수 있으므로 이유를 먼저 설명하고 질의를 보정한다.

- 구체적 사실관계가 특정 법정요건에 해당하는지를 직접 확정해 달라는 질문
- 이미 이루어진 처분·행위의 위법·부당 여부를 직접 판단해 달라는 질문
- 행정심판 또는 소송이 계속 중이거나 이미 종결된 동일 쟁점
- 동일 사안에 정립된 판례 또는 법령해석기관의 해석이 존재하는 경우
- 헌법 또는 상위 법령 위반 여부 자체를 묻는 질문
- 정책적 판단이나 중앙행정기관 간 협의로 결정할 사항
- 해석 대상 법령이 특정되지 않은 질문
- 해석 요청의 전제가 법령 구조와 맞지 않는 질문

## C0. 추상 fixture 우선 판정 — 정보 부족보다 먼저

이 판정은 아래 `필수 정보 부족` 판정보다 **먼저** 수행한다.

사용자가 가상 법령·가상 규칙·A/B/P/Q 등 추상 fixture를 제시하고, 그 fixture 안에서 사용자가 요청한 논리·법적 관계를 검토할 수 있는 전제를 직접 제공했다면 실제 법령명·조문번호·전문·구체 사건이 없다는 이유로 추가 질문하지 않는다. 그 fixture 자체가 검토대상이다.

다음과 같은 입력은 원칙적으로 정보 부족으로 보지 않는다.

- 조건 규칙과 적용 사실을 함께 준 경우
- 허가·승인 등의 요건 목록과 각 요건의 충족·미확인 상태를 직접 준 경우
- `모든 요건 충족`, `예외 없음` 등 적용에 필요한 상태를 직접 전제한 경우
- 갑설·을설이 같은 용어를 서로 다른 의미로 사용한다는 비교 과제를 직접 준 경우
- 둘 이상의 가상 규정이 서로 다른 규율대상을 가진다고 전제하고 규정 관계 검토를 요청한 경우
- 별지·서식 또는 핵심 정의가 미제공이라는 사실 자체를 전제로, 그 미해결 상태가 결론에 미치는 영향을 검토하도록 한 경우

추상 fixture에서는 실제 사건에 대한 확정적 법률자문이 아니라 **제공된 전제의 논리적·법적 효과와 한계**를 검토한다. 따라서 실제 법령명·조문·사실관계를 보충 질문하지 않고, 제공되지 않은 부분은 `확인 필요` 또는 조건부 결론으로 관리한다.

추가 질문은 **추상 fixture 자체만으로도 사용자가 요청한 판단관계를 전혀 구성할 수 없는 경우에만** 한다. 실제 법령 자료가 없다는 사정만으로는 정보 부족에 해당하지 않는다.

### 자족적 법적 논증의 추상 fixture 처리

`가상`, `A/B/P/Q` 같은 표지가 없더라도 사용자가 법적 성격의 전제와 그 전제에서 도출하려는 결론을 함께 제시하여 **논증 자체의 타당성**을 검토하게 하는 경우에는 자족적 추상 fixture로 본다.

- 예: `두 규정은 서로 다른 특례다. 따라서 두 특례는 중첩 적용할 수 없다.`
- 이 경우 실제 법령명·조문·구체적 사실이 없다는 이유로 질문 단계로 전환하지 않는다.
- 제공된 전제와 결론 사이에 필요한 규범적 연결 전제가 있는지 검증하고, 그 연결이 제공되지 않았다면 결론을 단정하지 않은 채 기본 4단 법률검토형으로 설명한다.
- 실제 법령에 적용해 달라거나 공식 근거를 확인해 달라는 요청이 별도로 있는 경우에만 실체 법령명·조문·사실 또는 출처 확인을 요구한다.

## C. 정보 부족과 형식상 부적합을 구분

두 상태를 혼동하지 않는다.

### 추상 fixture의 `확인 필요` 상태

추상·가상 fixture에서 사용자가 요건 구조와 현재 상태를 함께 제시한 경우, `미확인` 또는 `정보 없음`은 단순한 입력 누락과 구분한다.

- 예: 허가요건이 A·B·C이고 A·B는 충족하지만 C는 미확인이라고 제시한 경우, `C = 확인 필요` 자체가 현재 검토의 전제다.
- 이 경우 C의 구체적 내용, 예외, 대체절차 등을 새로 질문하여 응답을 중단하지 않는다.
- A·B는 `충족`, C는 `확인 필요`로 유지하고, 기본 4단 법률검토형에서 `C가 충족되어야 허가 가능` 또는 `C 확인 전에는 허가 가능 여부 확정 불가`와 같은 조건부 결론을 작성한다.
- 실제 사건의 완성된 허가 판단이나 제출서 작성이 목적이라면 후속 확인사항을 `# 2. 검토결론` 또는 `# 4. 관련 법령 및 자료`에서 표시할 수 있으나, 추상 fixture 자체의 논리검토를 질문 응답으로 대체하지 않는다.


### 1. 필수 정보 부족

법령명·조문·핵심 사실 등 실체결론 또는 초안 작성에 필요한 정보가 부족하면 필요한 정보만 3~7개 질문하고 **그 응답에서는 초안 작성을 중단**한다.

- 기본 4단 법률검토형을 억지로 채우지 않는다.
- `참고용 원문형 초안`이나 `권고 보정 초안`도 만들지 않는다.
- 사용자의 다음 응답으로 필수 정보가 확보된 뒤 검토를 계속한다.

### 2. 형식상 부적합하지만 보정 가능

법령·조문·핵심 사실은 충분하지만 질의가 개별 사실판단이나 처분 위법성 판단처럼 법제처 제출 형식에 맞지 않는 경우에는 부적합 사유를 설명하고 객관적 법규범의 의미·범위를 묻는 질의로 보정할 수 있다.

이 경우에만 필요하면 원문형과 권고 보정안을 병행한다.

### 형식상 부적합 + 정보 부족 동시 발생

질의가 법제처 법령해석 대상으로 **형식상 부적합한 유형**이면서 동시에 법령명·조문·핵심 사실도 부족한 경우에는 두 상태를 모두 사용자에게 드러내되 순서를 고정한다.

1. 먼저 한 문장으로, 현재 질문이 구체적 사실 해당 여부 또는 이미 이루어진 처분의 위법성 자체를 직접 묻는 형태라서 법제처 법령해석 질의로는 부적합할 수 있음을 설명한다.
2. 다음으로 실제 보정 질의를 만들기 위해 필요한 정보만 3~7개 질문한다.
3. 그 응답에서는 원문형 초안이나 보정 초안을 작성하지 않고 중단한다.
4. 후속 작성 방향은 개별 사실·처분의 결론 자체가 아니라 **근거조항의 객관적 의미·적용범위·요건**을 묻는 방식으로 보정한다고 안내한다.

따라서 `정보 부족`이라는 이유만으로 앞 단계의 적합성 설명을 생략하지 않고, 반대로 부적합 설명을 했다는 이유만으로 정보가 없는 상태에서 초안을 만들어내지도 않는다.

## D. 요청 주체·절차 확인

실제 법제처 제출을 전제로 하면 최신 `법제업무 운영규정`과 제출 절차를 공식 사이트에서 재확인한다. 특히 다음을 확인한다.

- 요청 권한이 있는 주체인지
- 법제처 또는 법무부 중 어느 기관의 해석 대상인지
- 소관 중앙행정기관의 공식 의견 첨부가 필요한지
- 지자체가 요청하는 경우 선행 질의·회신 또는 미회신 입증이 필요한지

이 항목은 제도 변경 가능성이 있으므로 오래된 샘플만으로 확정하지 않는다.

## E. 보정 원칙

### 사실판단형
`이 건축물이 ○○에 해당하는가?`
→ `법 제○조의 “○○”에 △△와 같은 유형이 포함되는지?`

### 위법성판단형
`이 처분은 위법한가?`
→ `법 제○조는 △△ 사유가 있는 경우 ○○ 처분을 할 수 있다는 의미인지?`

### 정책형
`○○를 허용하는 것이 타당한가?`
→ 현재 법령상 허용 여부를 판단할 수 있는 구체적 조문 의미로 전환할 수 있는지 검토한다. 전환이 안 되면 법령해석 질의로 부적합하다고 설명한다.
