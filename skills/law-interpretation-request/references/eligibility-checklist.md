# 법령해석 대상 적합성 내부 체크리스트

이 체크리스트는 **내부 판단용**이다. 법제처 제출용 최종 문안의 4~8번 항목으로 출력하지 않는다.

## A. 기본 적합성

- [ ] 해석 대상이 법률·대통령령·총리령·부령 등 법령의 규정인가?
- [ ] 해석 대상 법령과 조문이 특정되어 있는가?
- [ ] 질문의 전제사실과 해당 조문 사이에 실질적 연관성이 있는가?
- [ ] 단순 정책 선택이 아니라 법규범의 의미·범위를 묻는가?
- [ ] 문언상 결론이 완전히 명백하여 별도 해석이 불필요한 사안은 아닌가?

## B. 제외 가능성이 큰 유형

다음이면 법제처 법령해석 대상으로 부적합할 수 있으므로 이유를 먼저 설명하고 질의를 보정한다.

- 구체적 사실관계가 특정 법정요건에 해당하는지를 직접 확정해 달라는 질문
- 이미 이루어진 처분·행위의 위법·부당 여부를 직접 판단해 달라는 질문
- 행정심판 또는 소송이 계속 중이거나 이미 종결된 동일 쟁점
- 동일 사안에 정립된 판례 또는 법령해석기관의 해석이 존재하는 경우
- 헌법 또는 상위 법령 위반 여부 자체를 묻는 질문
- 정책적 판단이나 중앙행정기관 간 협의로 결정할 사항
- 해석 대상 법령이 특정되지 않은 질문
- 해석 요청의 전제가 법령 구조와 맞지 않는 질문

## C. 정보 부족과 형식상 부적합을 구분

두 상태를 혼동하지 않는다.

### 1. 필수 정보 부족

법령명·조문·핵심 사실 등 실체결론 또는 초안 작성에 필요한 정보가 부족하면 필요한 정보만 3~7개 질문하고 **그 응답에서는 초안 작성을 중단**한다.

- 기본 4단 법률검토형을 억지로 채우지 않는다.
- `참고용 원문형 초안`이나 `권고 보정 초안`도 만들지 않는다.
- 사용자의 다음 응답으로 필수 정보가 확보된 뒤 검토를 계속한다.

### 2. 형식상 부적합하지만 보정 가능

법령·조문·핵심 사실은 충분하지만 질의가 개별 사실판단이나 처분 위법성 판단처럼 법제처 제출 형식에 맞지 않는 경우에는 부적합 사유를 설명하고 객관적 법규범의 의미·범위를 묻는 질의로 보정할 수 있다.

이 경우에만 필요하면 원문형과 권고 보정안을 병행한다.

## D. 요청 주체·절차 확인

실제 법제처 제출을 전제로 하면 최신 `법제업무 운영규정`과 제출 절차를 공식 사이트에서 재확인한다. 특히 다음을 확인한다.

- 요청 권한이 있는 주체인지
- 법제처 또는 법무부 중 어느 기관의 해석 대상인지
- 소관 중앙행정기관의 공식 의견 첨부가 필요한지
- 지자체가 요청하는 경우 선행 질의·회신 또는 미회신 입증이 필요한지

이 항목은 제도 변경 가능성이 있으므로 오래된 샘플만으로 확정하지 않는다.

## E. 보정 원칙

### 사실판단형
`이 건축물이 ○○에 해당하는가?`
→ `법 제○조의 “○○”에 △△와 같은 유형이 포함되는지?`

### 위법성판단형
`이 처분은 위법한가?`
→ `법 제○조는 △△ 사유가 있는 경우 ○○ 처분을 할 수 있다는 의미인지?`

### 정책형
`○○를 허용하는 것이 타당한가?`
→ 현재 법령상 허용 여부를 판단할 수 있는 구체적 조문 의미로 전환할 수 있는지 검토한다. 전환이 안 되면 법령해석 질의로 부적합하다고 설명한다.
