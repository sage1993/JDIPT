# Architecture

## 목표

JDIPT는 **법령 데이터 수집**과 **법령해석 논증·작성**을 분리한다.

```text
사용자 질의
   │
   ▼
법령해석 Skill
   │
   ├─ 적합성 점검
   ├─ 질의 보정
   ├─ 문언·체계·목적·연혁 분석
   │
   ▼
Korean Law MCP
   │
   ├─ 현행 법령 조회
   ├─ 결정례/해석례 조회
   ├─ 연혁·관련 규정 탐색
   └─ 인용 검증
   │
   ▼
출처 검증
   │
   ▼
법제처 요청서 1~3 / 내부 검토문
```

## 책임 경계

### JDIPT
- 요청 목적과 질의 유형 판단
- 법령해석 대상 적합성 판정
- 법적 쟁점 구조화
- 갑설·을설 구성
- 문서 형식·문체 통제
- 조사 결과를 제출 가능한 문안으로 변환

### korean-law-mcp
- 국가법령정보센터 기반 식별·검색·본문 조회
- 판례·법령해석례 등 결정례 조회
- 연혁/시점 비교
- 인용 검증 및 관련 분석

## 의존성 정책

업스트림 MCP 소스는 vendor하지 않는다. 이유는 다음과 같다.

1. 업스트림 보안·성능 수정이 빠르게 반영되는 편이 유리함
2. JDIPT의 핵심 자산은 법령해석 워크플로와 문서 품질 규칙임
3. 소스 복제 시 동기화 비용과 책임 경계가 불필요하게 커짐

따라서 `package.json`에서 검증된 버전을 고정하고, 별도 PR로 업그레이드한다.
