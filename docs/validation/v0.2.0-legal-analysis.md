## E26 자동 적용 PASS 조건

새 컨텍스트마다 Plugin명, Skill명, `@jdipt`를 입력하지 않고 E26 프롬프트를 실행한다. 세 번 모두 다음 H1 구조가 나타나야 한다.

```markdown
# 1. 질의요지
# 2. 검토결론
# 3. 검토이유
# 4. 관련 법령 및 자료
```

추가 조건:

- `# 2. 검토결론`에서 상세 이유보다 먼저 결론을 제시한다.
- 단일 쟁점을 `법적 정의`, `적용 규정`, `사안 적용`, `문제 발생 지점`, `해석` 등의 단계별 소제목으로 과분할하지 않는다.
- 공식자료 링크 정책을 유지한다.
- 내부 논리검증의 기호화·점수·오류분류명을 노출하지 않는다.
- 한 번이라도 구 1~6 구조 또는 임의 구조가 나타나면 최종 release 판정은 `BLOCKED`다.
