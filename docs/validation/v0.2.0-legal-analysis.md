# JDIPT v0.2.0 법률분석 행동검증

## 1. 1차 검증 환경 판정

**판정: `INVALID_ENVIRONMENT`**

검증 요청에서 확인된 당시 활성 JDIPT Plugin은 `jdipt@sage1993` **v0.1.0**이었다. 이 검증의 대상은 v0.2.0 release 행동이어야 하므로, v0.1.0 활성 Plugin에서 나온 출력은 v0.2.0의 PASS/FAIL 결과로 계산하지 않는다.

로컬 checkout의 파일은 다음과 같이 v0.2.0을 선언하고 있다.

- `.codex-plugin/plugin.json`: `version: 0.2.0`
- `package.json`: `version: 0.2.0`
- 대상 Skill: `skills/law-interpretation-request/SKILL.md`

그러나 로컬 파일의 버전이 활성 Plugin/Skill의 resolved source와 동일하다는 증거는 확인되지 않았다. 따라서 로컬 checkout만으로 활성 v0.2.0 행동을 대신 실행하지 않았다.

## 2. 실행 결과

v0.2.0 설치본을 새 독립 컨텍스트에서 호출할 수 없는 환경이므로 실제 모델 출력 행동은 실행되지 않았다. `PASS`를 추정하지 않았으며, 다음 테스트는 모두 v0.2.0 release 결과로 `NOT_EXECUTED`이다.

| Eval | 요구 컨텍스트 | 결과 | 사유 |
|---|---|---|---|
| E1~E25 | 매 테스트마다 새 독립 컨텍스트에서 `$law-interpretation-request` 명시 호출 | `NOT_EXECUTED` | 활성 Plugin이 v0.1.0 |
| E26-1~E26-3 | Skill명·`$law-interpretation-request`·`@jdipt` 없는 새 독립 컨텍스트 각 1회 | `NOT_EXECUTED` | v0.2.0 Plugin 자동 적용 환경 미확보 |
| E27~E38 | 매 테스트마다 새 독립 컨텍스트에서 `$law-interpretation-request` 명시 호출 | `NOT_EXECUTED` | 활성 Plugin이 v0.1.0 |

따라서 이 기록에는 v0.2.0 행동에 대한 `PASS` 또는 `FAIL` 판정이 없다. 독립 컨텍스트 재사용 여부와 무관하게, 실행 대상 버전이 유효하지 않은 상태에서 결과를 산출하지 않았다.

## 3. 환경 진단으로 보존하는 기존 관찰

기존 기록에는 v0.2.0 검증으로 서술된 실행 관찰이 있었으나, 활성 Plugin이 v0.1.0이었다는 환경 판정에 따라 아래 내용은 v0.2.0 release 행동 결과가 아니라 **환경 진단 자료**로만 보존한다. 기대값을 낮추거나 계약을 수정하지 않았다.

### 3.1 기존 실패 관찰

| Eval | 실제 출력 관찰 | 기대 출력/계약 | 우선 확인할 contract |

이 관찰들은 계약 위반 가능성을 보여주는 자료이지만, v0.2.0 resolved Skill에서 재현된 결과가 아니므로 이번 기록에서 v0.2.0 `FAIL`로 확정하지 않는다. 유효한 v0.2.0 환경이 확보되면 해당 eval을 새 독립 컨텍스트에서 다시 실행하고, 실패 시 실제 출력·기대 출력·contract를 대조해 원인을 특정해야 한다.

### 3.2 기존 통과 관찰의 취급

기존 기록의 일부 `PASS` 관찰 역시 동일한 이유로 v0.2.0 `PASS`로 승계하지 않는다. v0.2.0 설치본 manifest와 resolved Skill source를 확인한 새 컨텍스트에서 다시 실행해야 한다.

## 4. 실패 원인 판단 및 수정 범위

이번 실행에서 v0.2.0 행동 실패를 확정하지 않았다. 따라서 기대값을 낮추는 변경, 광범위한 자동 수정, Skill/contract 파일 수정은 수행하지 않았다.

환경 진단 자료상 우선 확인할 문제 영역은 다음과 같다.

1. 최종 출력의 H1 구조 및 법제처 모드 제목 계약
2. 자료 부족 시 질문만 하고 중단하는 계약
3. Skill 호출 문자열과 내부 논리 흔적의 비노출 계약
4. 제공된 가상 정의·본칙·예외·사실의 보존 계약
5. 확인되지 않은 공식 URL 생성 금지 계약

## 5. 유효한 재검증 조건

다음 조건을 모두 충족한 뒤에만 E1~E38을 v0.2.0 release 행동 결과로 계산한다.

- 활성 Plugin manifest가 `jdipt@sage1993` v0.2.0임을 확인
- resolved `law-interpretation-request` Skill source가 v0.2.0 계약임을 확인
- E1~E25 및 E27~E38을 각각 새 독립 컨텍스트에서 `$law-interpretation-request`와 함께 실행
- E26을 Skill명·`$law-interpretation-request`·`@jdipt` 없는 새 독립 컨텍스트에서 3회 실행
- 각 테스트에서 사용자가 보게 되는 최종 출력만 평가
- 실행 불가 테스트는 `NOT_EXECUTED`로 기록하고 `PASS`로 추정하지 않음
