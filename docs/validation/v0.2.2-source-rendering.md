## Root cause evidence

v0.2.1 post-merge deployment smoke reproduced two failures in an explicit JDIPT invocation against the real-law 지식산업센터 question.

### RED-A — referenced source resolution gap

Observed behavior:

- 시행규칙 제24조 본문이 별지 제19호서식을 직접 참조한다는 사실까지 확인했다.
- 그러나 별지 제19호서식의 실제 문언을 직접 확인하지 않은 채 조사 단계를 종료했다.
- `지식산업센터 신설`과 `건축물 신축`의 개념관계를 해결하지 않은 상태에서 `가능합니다`라는 확정 결론을 출력했다.
- 시행규칙 제6조의 `기존 건축물이 있는 경우` 문언과 제7조의 기존 승인사항 변경 규정을 구별하지 않고 결론 근거로 묶었다.

Root cause:

현재 Source Completeness 계약은 관련 별표·별지서식을 `필요한 범위에서 확인`하도록 요구하지만, **본문이 핵심 별표·별지서식을 직접 참조한 경우 그 참조자료의 실제 문언을 확인하거나 확인 실패 상태를 명시적으로 해소하기 전에는 source resolution을 완료할 수 없다는 hard block이 부족하다.**

### RED-B — final rendering gate regression

Observed behavior:

- 동일 실행의 최종 답변이 `결론적으로, 가능합니다.`로 시작했다.
- 기본 출력 계약인 `# 1. 질의요지 → # 2. 검토결론 → # 3. 검토이유 → # 4. 관련 법령 및 자료`가 모두 누락됐다.
- 즉 장시간 조사·도구 호출 후 Final Rendering Gate가 실제 전송 직전에 재적용되지 않았다.

Root cause:

현재 Rendering Gate는 H1 계약을 설명하지만, **최종 초안 자체의 첫 비공백 줄·H1 개수·정확한 문자열·순서를 마지막 전송 직전에 다시 검사하고 불일치 초안을 폐기한다는 hard-fail 조건이 충분히 강하지 않다.**

## Implemented changes

### Referenced Source Resolution Hard Gate

- 공식 조문이 결론에 중요한 별표·별지서식·부표·부록을 직접 참조하면 해당 자료를 필수 확인자료로 승격한다.
- 원문 참조자료를 실제로 확인하지 못하면 `참조자료 확인 실패` 상태로 유지하고 확정 결론을 BLOCK한다.
- 정부24·검색요약·2차 안내자료는 원문 별표·별지서식을 대체하지 않는다.
- `설립승인사항 변경`과 `기존 일반 건축물의 최초 전환`을 자동 동일시하지 않는다.
- `신설`과 `건축물 신축`을 정의·문언 근거 없이 동일시하지 않는다.

### Final Rendering Hard Gate

- 기본 모드 최종 답변의 첫 비공백 줄을 정확히 `# 1. 질의요지`로 고정한다.
- 최상위 H1은 정확히 4개이고 기존 문자열·순서를 그대로 사용해야 한다.
- 첫 H1 이전의 `결론적으로`, 검토 결과, Skill 적용 안내 등 사용자용 서론을 금지한다.
- 검사 실패 초안은 부분 수정하지 않고 폐기 후 재렌더링하며, 재렌더링 결과를 다시 검사한다.
