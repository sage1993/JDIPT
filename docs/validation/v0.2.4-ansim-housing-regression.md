### Root-cause classification

#### ASH-01 — Oracle defect, moved to PR #15

All three captured answers identified the current general target-site minimum as **1,000㎡**, identified the separate **5,000㎡** branch, rejected the historical **500㎡** value as the current general minimum, and cited the current Seoul operating standard.

Direct review of the official current `안심주택 건립 및 운영기준` confirmed that the general business target-site minimum is 1,000㎡. The prior Oracle required `PROMOTION_1000_DISTINCTION` and `UNCERTAINTY_PRESERVED`, which rejected these current-source-grounded answers for the wrong reason.

The corrected PR #15 Oracle replayed the captured ASH-01 answers at **3/3 PASS** before the latest evaluator-stack sync. PR #15 requires one fresh static validation/replay after that sync, but no new ASH-01 live run is required if replay remains 3/3.

#### ASH-06 — mixed evaluator/runtime defect

The latest three outputs expose three distinct mechanisms.

1. **Specific legal-effect loss during synthesis**
   - outputs preserved or discovered the 250m base and 350m + integrated-review branch but rendered the latter as generic `350m까지 완화 가능`
   - the material source effect is a special **business-target-site designation** path, not merely a distance relaxation

2. **Defined-category / direct-authority incompleteness**
   - one run omitted the 250m base / 350m exception structure entirely while answering zoning, road and adjoining conditions
   - another run showed a direct law-search failure before fallback research
   - when an operating standard restates a statutory category/exception, the directly defining statute/regulation/ordinance must be resolved when reasonably accessible; original-source failure is not treated as rule absence

3. **Mutable-standard temporal rendering omission**
   - some answers cited or used a revision artifact but did not preserve verified current/effective-version status in the final answer
   - a mutable operating standard that materially supports the conclusion must carry verified revision/effective-date/current-status metadata through final synthesis; a document link alone is insufficient

The evaluator also produced one **false positive** by combining an unrelated `지정` token elsewhere in the answer with `350m + 통합심의`. PR #13 now fixes that matcher by requiring relation-bound proposition evidence.

### Current PR #14 behavior contracts

The runtime patch is intentionally generic and contains no Ansim-specific numeric answer literals.

- preserve a defined eligibility category's material boundary and exception
- preserve source-specific legal effects such as designation / recognition / approval instead of replacing them with generic relaxation or vague possibility
- apply **Direct Defining Authority Gate** when guidance restates a legally defined category/exception
- apply **Mutable Standard Temporal Status Gate** when an amendable operating standard materially supports the conclusion
- keep compound-issue coverage, source effect and current/effective status through final synthesis
