### Root-cause classification

#### ASH-01 — Oracle defect, moved to PR #15

All three answers identified the current general target-site minimum as **1,000㎡**, identified the separate **5,000㎡** branch, rejected the historical **500㎡** value as the current general minimum, and cited the current Seoul operating standard.

Direct review of the official current `안심주택 건립 및 운영기준` confirmed that the general business target-site minimum is 1,000㎡. The prior Oracle required `PROMOTION_1000_DISTINCTION` and `UNCERTAINTY_PRESERVED`, which rejected these current-source-grounded answers for the wrong reason.

Therefore:

- do not add ASH-01-specific runtime rules to the Skill
- correct the Oracle/current-standard contract separately in PR #15 (`fix/ansim-oracle-current-rule-alignment`)
- re-score the already captured ASH-01 answers after that evaluator correction before doing another live run

#### ASH-06 — runtime behavior failure

The three outputs show two distinct failures:

1. **defined-category coverage omission**
   - one run omitted the 250m base rule and 350m exception structure entirely while still answering zoning/road/adjoining conditions
2. **specific legal-effect loss during synthesis**
   - the other runs found the 250m base and the 350m + integrated-review branch, but rendered the latter only as `350m까지 완화 가능`
   - the source rule's material effect is a special **business-target-site designation** path, not a generic distance relaxation

The latest PR #14 patch therefore removes the earlier ASH-01-motivated quantitative-scope contract and narrows behavior enforcement to:

- preserve a defined eligibility category's material boundary and exception when the category is material to the issue
- preserve source-specific legal effects such as designation / recognition / approval instead of replacing them with a generic relaxation or vague possibility
- keep compound-issue coverage through final synthesis
