# JDIPT v0.2.1 Counterevidence Gate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** JDIPT가 잠정 결론과 긴장관계에 있는 관련 하위법령·별표·별지서식·절차규정을 누락하지 않고, 발견된 중대한 반대근거를 해결하지 않은 채 확정 결론을 내리지 않도록 v0.2.1 Counterevidence/Source Completeness Gate를 추가한다.

**Architecture:** 기존 `Legal Issue Mapping → Legal Interpretation → Logic Validation → Answer Rendering` 4단 구조는 유지한다. Counterevidence 책임은 Legal Issue Mapping에서 관련 자료 유형을 특정하고, Source Policy에서 공식자료를 탐색·위계화하며, Logic Validation에서 해결되지 않은 중대한 반대근거가 있는 확정 결론을 BLOCK하는 하위 Gate로 분산한다. Rendering은 새 사용자용 섹션을 만들지 않고 기존 4단 H1 또는 법제처 1~3 H1 안에 자연스럽게 반영한다.

**Tech Stack:** Markdown Skill/reference/eval contracts, Python 3.13 validator, Node.js >=20.19.0, `korean-law-mcp@4.12.1`, Codex Plugin Marketplace.

**Spec:** `docs/superpowers/specs/2026-08-22-jdipt-v0.2.1-counterevidence-design.md`

## Global Constraints

- 작업 브랜치: `docs/jdipt-v0.2.1-counterevidence`.
- 구현 완료 버전: `0.2.1`.
- `allow_implicit_invocation: false`와 explicit-only 정책을 유지한다.
- 기본 출력 H1은 `# 1. 질의요지 → # 2. 검토결론 → # 3. 검토이유 → # 4. 관련 법령 및 자료`를 유지한다.
- 법제처 전용 출력 H1은 기존 1~3 계약을 유지한다.
- URL provenance와 Output Hygiene 계약을 약화하지 않는다.
- E1~E38의 법적·논리적 기대행동은 변경하지 않는다. E26의 설치 버전 식별자만 v0.2.1 릴리스 검증에 맞게 동기화할 수 있다.
- E39/E40은 외부 MCP 상태와 무관하게 재현 가능한 가상 fixture로 작성한다.
- 반대근거를 반드시 하나 생성하는 규칙을 만들지 않는다.
- 별표·별지서식을 상위법보다 우위에 두지 않는다.
- MCP 서버 코드나 `korean-law-mcp` 버전은 변경하지 않는다.
- `main` 병합, tag, release는 사용자 명시 승인 전 금지한다.

```markdown
## E39. Counterevidence — 별지서식 충돌형
프롬프트: `가상 법률 제10조는 "A센터를 설립하려는 자는 승인을 받아야 한다"고 규정하고 신축 제한은 두지 않는다. 가상 시행령은 A센터의 구조·입주·시설 요건만 규정한다. 가상 시행규칙 별지 신청서는 신청 유형을 "신설 / 증설"로만 구분한다. 기존 B공장 건축물이 A센터 구조·입주·시설 요건을 모두 충족하는 경우, 건축물을 새로 신축하지 않아도 A센터 설립승인을 받을 수 있는지 일반 법률검토형으로 검토해줘.`
기대: 법률에 신축 제한이 없다는 이유만으로 즉시 가능 결론을 내리지 않는다. 별지 신청서의 `신설 / 증설` 문구를 결론과 긴장관계에 있는 자료로 검토하고, `A센터 신설`과 `건축물 신축`이 동일 개념인지가 문제 발생 지점임을 논증한다. 별지서식만으로 즉시 불가라고 단정하지 않으며, 서식의 기능과 상위법 관계가 해결되지 않으면 조건부 결론으로 낮춘다. 기본 4단 H1을 유지한다.
```

```markdown
## E40. 규정 부재 논증 Counterexample
프롬프트: `가상 법률은 "A시설의 허가를 받아야 한다"고 규정하고 기존 시설의 전환을 금지하지 않는다. 가상 시행령에는 추가 제한이 없다. 가상 시행규칙 별지 신청서는 신청 유형을 "신규 설치 / 증설"로 표시한다. 기존 B시설의 용도만 A시설로 변경하려는 경우 허가 가능 여부를 일반 법률검토형으로 검토해줘.`
기대: `법률에 금지 규정이 없음 → 가능`이라는 자동 추론을 하지 않는다. 별지서식과 법률 본문의 관계를 검토하되 별지서식이 법률보다 상위 효력을 가진 것처럼 처리하지 않는다. 관계를 해결할 수 없으면 조건부 결론을 사용하고, 존재하지 않는 추가 반대근거를 만들어내지 않는다. 기본 4단 H1을 유지한다.
```
