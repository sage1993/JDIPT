# JDIPT v0.2.1 Counterevidence Gate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 잠정 결론을 제한하거나 뒤집을 수 있는 관련 법적 자료를 놓치지 않고, 발견된 중대한 반대근거를 해결하지 않은 채 확정 결론을 출력하지 않도록 JDIPT v0.2.1을 보강한다.

**Architecture:** 기존 `Legal Issue Mapping → Legal Interpretation → Logic Validation → Answer Rendering` 4단 구조를 유지한다. Counterevidence는 새 최상위 단계가 아니라 Legal Issue Mapping과 Source Policy의 하위 Gate로 수집되고, Logic Validation에서 unresolved contrary authority를 BLOCK하며, Rendering에서는 기존 기본 4단 또는 법제처 1~3 구조 안에 자연스럽게 반영한다.

**Tech Stack:** Markdown Skill/reference/eval contracts, Python 3.13 validator, Node.js >=20.19.0, `korean-law-mcp@4.12.1`, Codex Plugin Marketplace.

**Spec:** `docs/superpowers/specs/2026-08-22-jdipt-v0.2.1-counterevidence-design.md`

## Global Constraints

- 작업 브랜치: `docs/jdipt-v0.2.1-counterevidence`.
- 구현 완료 버전: `0.2.1`.
- `allow_implicit_invocation: false`와 explicit-only 정책 유지.
- 기본 출력 H1과 법제처 전용 H1 계약 유지.
- URL provenance, Output Hygiene, Answer-first, Narrative Coherence 유지.
- E1~E38의 의미와 판정기준은 유지. E26의 설치 버전 식별자만 v0.2.1에 맞게 동기화.
- E39/E40은 MCP 없이도 재현 가능한 가상 fixture로 작성.
- 반대근거를 반드시 하나 만들어내는 규칙 금지.
- 별표·별지서식이 소속 법령의 일부일 수 있음을 전제로, 형식·위임근거·규범적 기능·상위법과의 정합성을 구분하여 평가. `법률 > 시행령 > 시행규칙 > 별지서식` 같은 단순 절대서열 규칙을 인코딩하지 않음.
- MCP 서버 코드와 `korean-law-mcp@4.12.1`은 변경하지 않음.
- `main` 병합, tag, release는 사용자 명시 승인 전 금지.
