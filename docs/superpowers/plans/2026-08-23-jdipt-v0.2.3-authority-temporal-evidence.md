# JDIPT v0.2.3 Authority·Temporal·Evidence Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** JDIPT가 법령해석 시 적용 기준시점, 자료 권위·법적 효력, 출처 명제와 분석추론을 구분하도록 기존 v0.2.2 fail-closed 계약을 확장한다.

**Architecture:** 기존 `Legal Issue Mapping → Source Completeness / Counterevidence → Legal Interpretation → Logic Validation → Answer Rendering` 흐름은 유지한다. 새 기능은 별도 데이터 플랫폼이 아니라 기존 reference contract 내부의 subgate로 구현한다. 행동평가는 E43~E46 네 케이스로 통합하고, 실제 LLM 실행은 별도 suite manifest의 Core 14 / Full active 26 구조를 따른다.

**Tech Stack:** Markdown Skill/reference contracts, Python 3 deterministic validation/pytest, JSON eval manifests, Codex CLI regression runner.

**Spec:** `docs/superpowers/specs/2026-08-23-jdipt-v0.2.3-authority-temporal-evidence-design.md`

**Evaluation design:** `docs/superpowers/specs/2026-08-24-jdipt-eval-suite-consolidation-design.md`

## Global Constraints

- `law-interpretation-request`는 explicit-only로 유지한다.
- `allow_implicit_invocation: false`를 변경하지 않는다.
- 기본 4단 Answer-first 출력과 명시적 법제처 1~3 출력 계약을 변경하지 않는다.
- `korean-law-mcp@4.12.1`을 유지한다.
- v0.2.2의 Abstract Fixture, Counterevidence, Referenced Source Resolution, URL Provenance, Final Rendering Hard Gate를 약화하지 않는다.
- package/plugin version은 이 PR에서 올리지 않는다.
- 기존 E1~E42 fixture는 삭제하지 않는다.
